# Dr. MOHAMMED THANZIL - Dental Surgeon Website

A modern, responsive, high-converting dental clinic website built with **React.js** and **Tailwind CSS v3**, tailored directly from the official Google Business profile.

---

## 🌟 Features Included

- **Clinic Branding & Identity:** Official clinic name `Dr. MOHAMMED THANZIL - Dental Surgeon`.
- **Google Profile Integration:**
  - 5.0 Star Google Rating badge with 74 verified Google Reviews.
  - Interactive Google Reviews summary bar (all 5 stars).
  - Featured patient review quote: *"Dr. Thanzil sir did my tooth fillings in less than 30 minutes."*
  - Direct links to the Google Maps / Google Business listing.
- **Authentic Clinic Imagery:** Displays real in-clinic operatory photos from the Google profile.
- **Full Services Grid:**
  - Fast & Painless Tooth Fillings (< 30 minutes)
  - Dental Implants
  - Bonding & Veneers
  - Check-ups & Digital Diagnosis
  - Cosmetic Whitening & Smile Design
  - Dentures & Bridges
  - Root Canal Therapy (Rotary Endodontics)
  - Wisdom Tooth & Oral Surgery
  - Emergency Dental Care
  - Pediatric Dentistry
- **Interactive Appointment Booking:**
  - Patient details, treatment dropdown, date picker, and morning/afternoon/evening time slots.
  - Direct 1-click **WhatsApp booking** pre-filled with patient details to `+91 94453 31683`.
  - Instant online booking confirmation with generated tracking ID.
- **Clinic Location & Extended Hours:**
  - Real-time `Open · Closes 9:00 PM` operational badge.
  - Interactive Google Maps embed with GPS navigation link.
  - One-click "Copy Address" button with live feedback.
  - Direct phone calling (`094453 31683` / `+91 94453 31683`).
- **Floating Quick-Action CTAs:** Mobile & desktop floating buttons for instant phone calls and WhatsApp messaging.
- **Interactive FAQ Accordion:** Answers for common patient queries regarding pain, duration, insurance, and emergency visits.

## 🚀 Getting Started

### Development Server
```bash
npm run dev
```
Runs at: `http://localhost:3000/`

### Production Build
```bash
npm run build
```

---

## ⚙️ Customization

All clinic details (address, phone numbers, working hours, doctor biography, services, and reviews) are centrally managed in:
```
src/data/clinicData.js
```
To update the street address or phone number, simply edit the values in `src/data/clinicData.js` and the entire website will update automatically!
